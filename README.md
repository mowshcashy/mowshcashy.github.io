# EBDAAI landing page

A static page: open `index.html`, or host the folder anywhere (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

- `index.html` — the page (Arabic first, with an English switch). Three.js (r128) and GSAP 3.12.5 load from cdnjs; fonts from Google Fonts.
- `img/` — pictures made with EBDAAI and screenshots of the app, sized for the web.
- `fonts/` — Dima Naskh (GPL, see `fonts/GPL.txt`) for the big Arabic words.
- `logos/` — model marks from LobeHub Icons (MIT), see `logos/README.md`.
